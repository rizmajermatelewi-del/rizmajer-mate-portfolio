# Rizmajer Máté — Portfolio

Personal portfolio site for Rizmajer Máté Levente, full-stack developer.

Built with React 19, Vite, Tailwind CSS, and GSAP.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Stack

- React + Vite
- Tailwind CSS
- GSAP (scroll animations)
- React Router
- Formspree (contact form)
